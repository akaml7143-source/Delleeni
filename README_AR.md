# دِلِّينِي — Delleeni

مشروع Flutter أولي لتطبيق خرائط ودليل جغرافي عراقي على Android.

## الموجود حالياً
- خريطة OpenStreetMap تفاعلية.
- واجهة عربية أولية.
- علامات تقريبية لمراكز مدن المحافظات العراقية الـ18.
- بحث محلي بأسماء المدن والمحافظات المدرجة فقط.
- زر طلب إذن GPS وعرض موقع الجهاز.
- GitHub Actions لتحليل المشروع واختباره وبناء APK عند الدفع إلى main أو يدوياً.

## بناء APK
يتولى سير العمل في `.github/workflows/android-apk.yml` إنشاء ملفات Android ثم تشغيل:
`flutter pub get`, `flutter analyze`, `flutter test`, `flutter build apk --release`.
بعد نجاح GitHub Actions، نزّل artifact باسم `delleeni-release-apk` من صفحة Actions.

## حدود مهمة
علامات المدن إحداثيات تقريبية وليست حدوداً رسمية. البحث ليس بحثاً وطنياً للعناوين. لا تتضمن هذه النسخة ملاحة turn-by-turn أو حركة مرور أو خرائط offline أو قاعدة بيانات خدمات. يجب التحقق من نتيجة Actions قبل اعتبار APK جاهزاً.

الخريطة تستخدم خوادم بلاطات OpenStreetMap القياسية؛ يجب الالتزام بسياسة الاستخدام والإسناد، والانتقال إلى مزود مناسب أو استضافة ذاتية إذا ازداد الاستخدام.
