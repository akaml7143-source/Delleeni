# خرائط العراق — الإصدار التأسيسي 0.2

## ما أُضيف في هذه النسخة
- شاشة خرائط عربية باستخدام MapLibre.
- عرض مواقع المحافظات الـ18 من قائمة داخل التطبيق.
- البحث المحلي عن اسم المحافظة (لا يشمل الشوارع والأحياء بعد).
- طلب إذن GPS أثناء الاستخدام، وقراءة موقع الجهاز، وإظهار نقطة موقعك على الخريطة.
- قاعدة بيانات PostGIS مع ملف SQL لإدخال مراكز المحافظات التقريبية.

## المتطلبات
- Flutter متوافق مع Dart 3.10 أو أحدث.
- Android SDK وAndroid Studio.
- اتصال إنترنت لتحميل نمط الخريطة الحالي.

## التشغيل
```bash
flutter pub get
flutter run
```

## ملفات مهمة
- `lib/main.dart`: واجهة الخريطة والبحث عن المحافظات وGPS.
- `database/schema.sql`: مخطط قاعدة البيانات.
- `database/provinces_seed.sql`: مراكز تقريبية للمحافظات.

## حدود النسخة
هذه ليست بعد نسخة ملاحة مكتملة أو جاهزة للنشر:
- مراكز المحافظات تقريبية وليست حدوداً إدارية رسمية.
- البحث حالياً يطابق أسماء المحافظات فقط.
- لا توجد بيانات طرق عراقية مستوردة في قاعدة البيانات حتى الآن.
- لا يوجد توجيه مسارات أو تعليمات صوتية أو ازدحام مباشر أو خرائط محمّلة دون إنترنت.
- لم يُنشأ APK ولم يُختبر على جهاز حقيقي في بيئة البناء الحالية.

## الخرائط وحقوق الاستخدام
النمط الحالي للتجربة هو OpenFreeMap Liberty. قبل النشر العام، اختر مزود بلاطات أو استضافة ذاتية مناسبة وتحقق من شروط الاستخدام والحدود التشغيلية.
يجب إظهار إسناد OpenStreetMap عند استخدام بياناته والالتزام بترخيص ODbL:
https://www.openstreetmap.org/copyright

## ملاحظة GPS
يطلب التطبيق الموقع فقط عند ضغط المستخدم على زر تحديد موقعي، ولا يطلب تتبعاً في الخلفية.
